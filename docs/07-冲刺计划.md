# 7 天冲刺计划（最快路径）

> 目标：**7 天做出"能播 + 界面像样"的可用版本**。这是最快速度下的真实数字，不是乐观宣传。
> 前提是按下面的**并行**方式推进；串行做（等环境好了再动手）就是 3 周。

---

## 先说清楚三件事

**① 最快 7 天冲的是这个，不是"全功能"**

| 目标 | 最快 | 现实（正常踩坑） |
|---|---|---|
| 播出第一个视频 | **4–5 天** | 7–8 天 |
| 能播 + 界面像样（首页/分类/详情/播放） | **7 天** | ~2 周 |
| 日常可用（+搜索/片库/设置/多源） | **12–14 天** | ~3 周 |
| 全功能（+libmpv/直播/弹幕渲染/WebDAV） | 5–6 周 | 6–8 周 |

**② 时间不在"写代码"上。** 我按整包交付（你可以粘完就编译），所以编码几乎不是瓶颈。
真正的固定成本只有三处，且都在你这边：

1. **Mac + Xcode 就绪**（Xcode 下载 10–15 GB，这一步今天就该开始）
2. **首次真机签名部署**（小白最容易卡，单独占一天）
3. **在 iOS 上跑通 Node 运行时**（全项目唯一的真风险点）

**③ 所以"最快"= 并行。** 你装环境的时候我在写代码；你编译的时候我在改 bug；
你贴报错我当轮回修好的完整文件。一天能推好几轮，而不是一天一步。
