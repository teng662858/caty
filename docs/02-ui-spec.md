## 0. 关于"最新 iOS"的诚实说明

设计稿与本文基于**稳定的 SwiftUI 结构**：`TabView` + `Tab`、`NavigationStack`、`LazyVGrid`、
`ScrollView` + `.scrollTransition`、`matchedTransitionSource` / `.navigationTransition(.zoom)`、
`.glassEffect` / `GlassEffectContainer`、`.searchable`、`.tabBarMinimizeBehavior(.onScrollDown)`。

这些是 iOS 18 / 26 一代已确立的 API。**iOS 27 SDK 若有新增或改名，以你 Mac 上实际编译结果为准** ——
我不会凭空断言没见过的新 API。好消息是：上面的结构都是向后兼容的写法，不会因为 SDK 升级而返工。

**设计语言落点**：Liquid Glass 只用在**浮层**（底部 tab bar、导航按钮、播放控制、弹窗），
**列表与内容区保持不透明**（海报/文字压在玻璃上会脏）。这是这套语言最容易被用错的地方。

## 1. 设计原则（决定"高级清爽"的四条）

1. **内容优先**：屏幕上出现面积最大的应该是海报/画面，不是装饰。底色压到 #07080A 一档，UI 元素靠 1px 描边 + 6% 白区分层级。
2. **材质克制**：玻璃只给"浮在内容之上"的层。tab bar 62% 不透明 + blur；内容卡用 6% 白玻璃。
3. **首屏永不空白**：运行时（Node）没就绪时，先渲染**缓存的上次首页 + 骨架占位**，再后台替换。空状态也必须有内容（骨架 ≤ 8 个占位卡）。
4. **一步可达**：播放路径最多 3 次点击（首页卡 → 详情「播放」→ 播放中）；分类/搜索/片库都在 tab 第一层。

## 2. 设计 Token

| 类别 | 值 |
|---|---|
| 间距 | 4 / 8 / 12 / 16 / 20 / 24（页面左右留白固定 **16**） |
| 圆角 | 海报 12、大卡/列表组 14–16、hero 16、按钮胶囊、tab bar 26、手机 52（仅稿） |
| 字号 | 大标题 32/700(-0.6)；区块标题 17/650；卡标题 12.5；正文 12.5；说明 11.5；tab 10.5 |
| 数字 | 进度/时长/评分一律 `.monospacedDigit()`，避免跳动 |
| 颜色 | 背景 `#07080A`；卡片 `rgba(255,255,255,.065)`；描边 `rgba(255,255,255,.09)`；主文 `#F2F4F7`；次文 66%；弱化 38% |
| 强调色 | **取自源配置的 `color` 调色板**（本项目默认 `#8CDA60`）。用户可在「设置 › 主题色」切换；不硬编码 |

| 动效 | 详情转场 zoom + 0.35s；列表滚动淡入（位移 ≤ 8pt）；播放器进入 0.4s 缩放；骨架 shimmer 1.6s。**全部尊重「减弱动态效果」** |
| 海报比例 | 竖版 2:3（112×168 / 104×156）；横版 hero 16:9 |

## 4. 逐屏版面规格

### ① 首页
| 版块 | 内容 | 规格 |
|---|---|---|
| 顶栏 | 大标题「首页」+ 搜索按钮 + 运行状态胶囊 | 状态胶囊：绿点 + 「运行中 / 启动中 / 已停止」 |
| Hero | 继续观看 | 16:9 圆角 16；左侧压暗渐变到 26%；信息层：`继续观看` → 剧名 → `第 N 集 · 已看 mm:ss` → 播放胶囊 → 3px 进度条 |
| 推荐行 | 每源一段 | 区块头：站点名 + 「换一批 · 更多 ›」；横向滚动 112×168 卡，间距 11 |
| 卡片 | 海报 + 角标 + 备注 + 标题 | 角标（左上）：更新集数/热；底部渐变条：`vod_remarks`（蓝光 4K / 更新至第 10 集） |
| 电影行 | 同上 | 站点越多段落越多；段数可配（默认每源 2 段） |
| 底部 | tab bar | 滚动时 `tabBarMinimizeBehavior(.onScrollDown)` 自动收起 |

### ② 分类
站点 chip 行（`horizontal` 胶囊，选中态用强调色 16% 底 + 35% 描边）→ 分类网格（2 列，74pt 高，含「N 部」计数）→
筛选行（类型/地区/年份/排序，`Menu` 弹出）→ 结果网格（3 列，无限滚动，距底 4 行触发下一页）。

### ③ 详情
沉浸头图（海报放大 + blur 14 + 双向径向渐变）→ 返回/分享按钮（玻璃圆钮）→ 126×189 海报 + 右侧信息
（标题 22/700、meta chip 行、评分、`播放` 主按钮 + 收藏/下载圆钮）→ 简介 3 行 + 「展开」→
线路分段（`线路一 · 4K` / `线路二` / `网盘`）→ 选集网格（5 列，42pt 高，当前集用实心强调色，已看集降亮度）。

**关键交互**：从列表进入时**先用列表已有的 `vod_id/vod_name/vod_pic` 立即渲染**，`detailContent` 异步补全 —— 不允许白屏。

### ④ 播放
全屏黑底 + 画面层 → 顶部（返回 / 标题·集数 / 投屏 / 画中画）+ 右上状态胶囊（`线路一 · 4K · 硬解`）→
中央播放/暂停玻璃大按钮 → 底部：时间行（`monospacedDigit`）→ 4pt 进度条（已播 / 缓冲 / 拖拽 knob）→
5 个操作钮：下一集 / 选集 / 弹幕 / 音轨 / 线路。

手势：左侧上下=亮度，右侧上下=音量，横向=进度，双击=暂停，长按=倍速。
异常：缓冲转圈 → 超时自动换线路 → 仍失败给出「换源播放」按钮（列出其它源的同一部片）。

### ⑤ 设置
分组列表（`Form` + 玻璃圆角组）：**源**（源管理 / 检查更新）→ **账号**（网盘账号 → WebView 打开 `http://127.0.0.1:<port>/website`）
→ **播放器**（硬解 / 倍速 / 跳过片头尾 / 弹幕）→ **外观**（主题色圆点 / 显示模式）
→ **运行时诊断**（`● 127.0.0.1:54321 · 62 MB` / 运行日志导出）。

### ⑥ 搜索
搜索框（聚焦时强调色描边 + 光标）→ 聚合开关胶囊 → 来源分段（`全部 12 / 神族九帝 7 / repl 4`）→
结果卡（74×104 缩略图 + 标题 + meta + **来源角标组** + 播放圆钮；多源命中用强调色）→ 搜索历史 chip。
输入防抖 400ms，多源并发，超时 8s 的源单独标注「未返回」而不是整页失败。

### ⑦ 片库
分段（收藏 / 历史 / 网盘）→ 历史行（58×82 缩略图 + 标题 + `第 N 集 · 时间` + 进度条 + 右箭头，左滑删除）
→ 收藏网格（3 列，长按菜单：移除 / 详情）→ 网盘（列出已登录的网盘：夸克/阿里/UC/115/PikPak/123/天翼…，点击进入浏览）。

### ⑧ 首次导入源
标题 + 说明 → 地址输入框（等宽字体，长 URL 自动折行）→ `开始导入` 主按钮 → `从剪贴板粘贴` 次按钮 →
**信任提示块**（第三方程序、可读写本地与发网络请求、可能保存网盘凭据、可随时暂停删除）→
三步进度（下载 → 校验 MD5 → 启动运行时），每步显示实测信息（体积、MD5 前 8 位、校验结果）。

| 弹幕 | bundle 的 `/danmaku` 或 `/v1/danmaku` |
| 网盘账号 | `http://127.0.0.1:<port>/website`（WebView 直接用源自带面板） |

| 运行状态胶囊 | `/msg` 桥的 `serverStarted` + 定期健康检查 |

## 7. 状态矩阵（每个列表页都必须实现全部 5 态）

| 态 | 触发 | 呈现 |
|---|---|---|
| 加载中 | 首次/刷新 | 骨架行（≥6 卡），**不用全屏转圈** |
| 空 | 源返回空 | 插画 + 文案 + 「换个分类/检查源」 |
| 错误 | 请求失败 | 文案 + 「重试」+ 展开错误详情（便于贴给源作者） |
| 离线 | 无网络 | 「已离线 · 显示缓存内容」顶部条 |
| 运行时未就绪 | Node 启动中/崩溃 | 顶部状态条 + 「重启运行时」，**页面仍显示缓存内容** |

## 8. SwiftUI 落地要点

```swift
TabView {
    Tab("首页", systemImage: "house") { HomeScreen() }
    Tab("分类", systemImage: "square.grid.2x2") { BrowseScreen() }
    Tab(role: .search) { SearchScreen() }          // 搜索用系统 search role
    Tab("片库", systemImage: "bookmark") { LibraryScreen() }
    Tab("设置", systemImage: "gearshape") { SettingsScreen() }
}
.tabBarMinimizeBehavior(.onScrollDown)             // 滚动收起，阅读更沉浸
.tabViewStyle(.sidebarAdaptable)                   // iPad 自动变侧栏（可选）
```

- **转场**：详情页用 `matchedTransitionSource(id:in:)` + `.navigationTransition(.zoom(sourceID:in:))`，播放器用 `.fullScreenCover` + 缩放。
- **网格**：`LazyVGrid(columns: [GridItem(.adaptive(minimum: 104), spacing: 11)])`；海报**固定尺寸**，避免图片加载导致布局抖动。
- **图片**：不要用 `AsyncImage`（无磁盘缓存、无复用）。自研 `PosterImage`：URLCache(50MB/500MB) + 内存 LRU + 取消 + 邻近预取（`onAppear` 取后 6 个）。
- **滚动性能**：每行 `Section` 独立 `LazyHStack`；避免在 body 里做字符串分割（`vod_play_url` 拆分在 ViewModel 做一次并缓存）。
- **玻璃**：`GlassEffectContainer` 包住底部工具条与浮动按钮；**不要**给 `LazyVGrid` 里的卡片加玻璃（滚动时开销大）。
- **动效克制**：`.scrollTransition` 只在 hero 与区块头上用。

## 9. 无障碍与适配

- 动态字体：全部用语义字号（`.headline`/`.subheadline`），海报卡标题允许 2 行；列表行最小高度随字号增长。
- VoiceOver：海报卡 label = `剧名，更新至第 10 集，按两下播放`；进度条提供 `accessibilityValue`。
- 减弱动态效果：关闭 zoom 转场与 shimmer（用静态占位）。
- 对比度：次文不低于 66% 白，强调色在深底上保持 ≥ 4.5:1。
- 横屏=播放器全屏；竖屏为主。iPad 走 `.sidebarAdaptable`（v1 可选）。

## 10. UI 构建顺序（与里程碑对齐，每步都能跑）

| 步骤 | 内容 | 归属 |
|---|---|---|
| U1 | 骨架 + tab 结构 + **运行时状态页**（端口/内存/日志） | M1 |
| U2 | 源管理 + 首次导入引导（信任提示） | M2 |
| U3 | 首页最小版（列表）+ 分类 + 详情（文本版，无海报） | M3 |
| U4 | 播放器页 + 线路/选集弹层 | M4 |
| U5 | 海报网格 + 详情沉浸头图 + zoom 转场 + 骨架 + 五态 | M5 |
| U6 | 搜索聚合 + 片库 + 外观主题色 + 动效打磨 + 无障碍 | M5 |

**做 UI 的顺序原则**：先把"能用"的粗版全链路打通（U3 用文字列表也行），再统一上海报和动效——
反过来做（先精修首页）会在协议和播放器还没稳定时反复重做。

## 11. 动效 Token

| 名称 | 用途 | 参数 |
|---|---|---|
| `motion.tap` | 按钮按下反馈 | 0.12s `easeOut`，缩放 0.97，松手回弹 |
| `motion.appear` | 列表项淡入 | 0.28s `easeOut`，位移 ≤ 8pt |
| `motion.zoom` | 列表 → 详情转场 | 系统 zoom（`matchedTransitionSource`），≈0.35s |
| `motion.playerIn` | 进入播放器 | 0.40s `spring(response: 0.42, dampingFraction: 0.86)` |
| `motion.panel` | Sheet / 弹层 | 用系统默认 detent 动画，不自定义 |
| `motion.shimmer` | 骨架屏 | 1.6s `linear` 无限循环 |
| `motion.progress` | 进度条数值变化 | 0.25s `easeOut`；**用户拖动时改为 0（跟手）** |
| `motion.toast` | 提示浮层 | 入场 0.18s、停留 1.8s、出场 0.18s |

**硬规则**
1. 同一屏同时进行的动效 ≤ 2 组。
2. 滚动过程中不启动新动效（避免掉帧）。
3. 打开「减弱动态效果」时：`zoom`／`shimmer` 退化为直切，其余时长压到 0.01s。

## 14. 浅色模式配色

设计稿只出了深色。浅色按下面这套 token 实施（**播放器永远深色，不跟随系统**）：

|---|---|---|
| 页面背景 | `#07080A` | `#F6F7F9` |

| 次文 | 白 66% | 黑 60% |
| 弱化 | 白 38% | 黑 38% |

## 19. 冷启动 · 首次流程 · 降级规则

### 19.1 冷启动顺序（**首屏绝不等运行时**）

```
1. Splash（≤0.6s，仅品牌，不做加载进度）
2. 读本地「源记录 + 上次首页缓存 + 收藏/历史」          ← 全本地，毫秒级
3. 立刻渲染首页（有缓存用缓存，无缓存用骨架）
4. 并行：启动所有启用源的 Node 运行时 + 检查源更新
5. 就绪一个源 → 替换一个源的内容（渐进渲染，不整页刷新）
```

| 指标 | 目标 |
|---|---|
| 首屏可见 | **≤ 1.5s**（用缓存） |
| 首个源就绪 | ≤ 8s；无 JIT 下放宽到 15s，超出显示 16.3 表里那条「运行时准备中」 |
| 全部源就绪 | ≤ 25s（后台完成，不阻塞交互） |

### 19.2 首次启动（无任何源）

不进空首页，**直接呈现"导入源"引导页**（即设计稿 ⑧，作为全屏页而非 sheet），
底部一行小字：`Caty 不含任何内容源，请导入你自己信任的源`。

### 19.3 降级规则

| 条件 | 行为 |
|---|---|
| Dynamic Type ≥ `.accessibility3` | 网格列数自动 −1；卡片标题限 1 行；tab 只留图标隐藏文字 |
| 竖屏 / 横屏 | **只有播放器支持横屏**，其余页面锁竖屏 |
| 内存告警（`didReceiveMemoryWarning`） | 清空图片内存缓存；必要时重启运行时 |
| 运行时全部失败 | 首页保留缓存内容 + 红条；设置页可诊断；其它功能（收藏/历史）仍可用 |
